# Recommendation Analysis

## 2026-09-20 분석 결론

요청은 잦은 0개 적중의 원인을 조사하고 적중률을 대폭 높이는 것이었다. 당첨 데이터 1~1242회, 실제로 추첨 전에 확정한 8회 추천을 분석했다. 비교한 대안 8개에서 개선 근거를 찾지 못했다. 따라서 성능 향상을 주장하거나 번호를 재추첨하지 않았고 실사용 v2 엔진을 유지했다.

### 실제 성적과 확률 기준

| 지표 | 실제 사전 추천 8회 | 무작위 이론값 |
| --- | ---: | ---: |
| 평균 적중 수 | 0.625개 | 0.800개 |
| 0개 적중 | 3/8회, 37.5% | 약 40.06% |
| 3개 이상 적중 | 0/8회, 0% | 약 2.3834% |

실제 평가 대상은 1234회 및 1236~1242회다. 1235회는 사전 추천이 없으므로 분모에서 제외하고 사후 생성하지 않았다. 최신 1243회 pending 추천 `3, 5, 11, 27, 30, 39`도 평가에 넣지 않으며 변경하지 않는다.

한 세트의 본번호 적중 수 H는 공정한 추첨 가정에서 초기하분포를 따른다.

`P(H=k) = C(6,k) C(39,6-k) / C(45,6)`

8회 총합이 관측값 5개 이하일 확률은 약 35.62%다. 같은 8회 무작위 추천의 평균 적중 양측 95% 예상 범위는 0.250~1.375개다. 현재 성적은 낮지만 특별히 비정상적인 실패라고 판단할 근거는 부족하다. 이는 엔진이 좋다는 증명도 아니다.

### 비교 설계

처음 260회는 준비 데이터다. 261~982회 722건을 선행 검증, 983~1242회 260건을 후반 검증에 사용했다. 각 목표 회차의 직전까지만 입력으로 주고 동일하게 6개 번호 1세트를 평가했다. 총 982회 예측을 전략당 수행했다. 데이터 순서를 섞거나 미래 당첨번호를 학습에 넣지 않았다.

후보, seed, 규칙은 결과를 출력하기 전에 코드로 고정했다. 다만 이미 존재하는 데이터로 지금 설계한 과거 검증이므로 완전히 새로운 데이터에 대한 전향적 검증은 아니다. 매주 다시 실행하면 후반 창도 움직인다. 후보나 기준을 수정할 때는 분석 정책 버전을 올리고, 개선 주장은 추첨 전 저장된 후속 성적에서 따로 확인해야 한다.

| 방식 | 선행 평균 | 후반 평균 | 후반 0개 적중 | 후반 3개 이상 |
| --- | ---: | ---: | ---: | ---: |
| 현재 v2 | 0.812 | 0.723 | 41.2% | 2.31% |
| 최근 52회 최다 출현 | 0.842 | 0.738 | 40.8% | 0.77% |
| 최근 260회 최다 출현 | 0.827 | 0.723 | 40.8% | 0.38% |
| 전체 최다 출현 | 0.770 | 0.800 | 41.5% | 3.85% |
| 최근 260회 최소 출현 | 0.805 | 0.758 | 44.6% | 2.31% |
| 최장 미출현 | 0.834 | 0.727 | 42.3% | 1.54% |
| 빈도·미출현 혼합 | 0.860 | 0.754 | 41.2% | 0.77% |
| 홀짝·합계 균형 | 0.819 | 0.781 | 39.6% | 1.92% |
| 직전 당첨번호 제외 | 0.813 | 0.796 | 40.0% | 2.31% |

모든 후반 평균은 무작위 이론 평균 0.8 이하이며 후보별 보정 p값은 모두 1이다. 전체 빈도 방식의 3개 이상 비율이 가장 높다는 이유만으로 사후 선택하면 다중 비교와 과적합 문제가 생긴다. 단순히 여러 seed를 시도해 가장 잘 맞은 번호를 채택하는 방식도 사용하지 않았다.

### 후보 규칙

- 최다/최소 출현: 해당 과거 구간의 본번호 출현 횟수 순서로 6개 선택. 동률은 회차별 고정 난수로 결정한다.
- 미출현: 직전 출현 이후 지난 회차 수가 큰 순서로 6개 선택한다.
- 혼합: 최근 260회의 `(출현 횟수 - 기대 횟수) / 이론 표준편차 + min(미출현 간격, 30) / 10` 상위 6개다.
- 균형: 균등 후보 중 홀수 2~4개, 22 이하 2~4개, 합계 100~180을 만족하는 첫 세트다. 1,000회 시도 한도 초과 시 실패한다.
- 직전 제외: 직전 당첨 본번호 6개를 뺀 39개에서 균등 후보를 만든다.
- seed: `npick-analysis-v1:전략ID:기준회차`. 비교 대상 현재 v2는 실제 엔진을 그대로 호출한다.

두 구간 모두 평균 적중 최소 +0.1개, 0개 적중 최소 -5%p, 3개 이상 비율이 이론값 이상이며, 평균 적중 합의 정확한 단측 p값에 8개 후보 Bonferroni 보정을 적용한 결과가 0.05 이하여야 검토 대상으로 표시한다. 보정은 평균 적중 검정의 후보 간 다중 비교를 대상으로 하며, 다른 지표의 유의성까지 주장하지 않는다. 통과해도 자동 배포하지 않고 사전 기록한 추가 검증을 요구한다.

### 구현 및 재현

```bash
npm run analyze
npm run check
```

분석은 외부 서비스나 추가 라이브러리 없이 실행된다. `data/recommendation-analysis.json`에는 두 구간의 전체 분포, 원 p값과 보정 p값, 실제 성적, 데이터 SHA-256이 들어 있다. JS 산출물은 앱에서 숫자 표를 표시하는 데 사용한다. `npm run update:data`와 정기 워크플로가 보고서를 함께 갱신한다. 이 문서는 해당 날짜의 분석 스냅샷이며 최신 숫자는 생성 보고서에 있다.

적중률을 높였다는 목표는 달성하지 못했다. 완료한 개선은 미래 정보가 섞이지 않는 비교 도구, 표본 수와 무작위 기준을 드러내는 성적 화면, 매주 재검증 및 기록 무결성 검사다. 세트 수를 늘리거나 구매를 늘리는 방식은 적용하지 않았다.

확률 기준은 [동행복권 로또6/45 안내](https://www.dhlottery.co.kr/lt645/intro)의 45개 중 6개 및 등위 규칙을 사용해 직접 계산했다.
