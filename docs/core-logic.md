# NPICK Core Logic

NPICK은 매주 정확히 3세트만 생성한다. 한 회차의 추천은 당첨 결과가 발표될 때까지 바뀌지 않으며, 결과가 데이터에 들어오면 3세트를 평가한 뒤 다음 회차 3세트를 생성한다.

## 주간 사이클

1. `scripts/update-lotto-data.mjs`가 매주 최신 당첨번호를 가져온다.
2. 기존 pending 추천의 목표 회차가 발표됐으면 세트별 적중 번호, 적중 수, 보너스, 등수를 평가한다.
3. 최신 당첨 회차 바로 다음 회차에 대한 기록이 없을 때만 새 추천을 만든다.
4. 새 추천과 누적 평가를 `data/weekly-recommendations.js`와 JSON 파일에 저장한다.
5. 정적 앱은 생성 파일을 읽어 이번 주 3세트, 지난주 평가, 누적 결과를 표시한다.

놓친 과거 회차는 사후 생성하지 않는다. 최신 회차가 오래되어 다음 추첨일의 판매 마감 시각(한국시간 20:00)이 지났으면 데이터 갱신을 실패 처리하고 새 추천을 만들지 않는다.

## 추천 생성

`src/core/recommendation-engine.js`는 최신 당첨 회차와 엔진 버전으로 결정적 seed를 만든다. 1~45를 seed 기반으로 한 번 섞은 뒤 앞의 18개를 6개씩 나눠 3세트를 만든다.

- 회차당 정확히 3세트
- 세트당 서로 다른 번호 6개
- 세 세트 전체에서 번호 중복 없음
- 같은 엔진 버전과 기준 회차는 언제 실행해도 같은 추천을 재현
- hot/cold, 최근 번호 회피, 미출현 간격, 이전 적중 피드백을 다음 번호 확률에 사용하지 않음

빈도와 미출현 통계는 화면의 참고 차트에만 사용하고 추천 번호에는 영향을 주지 않는다. 공정한 6/45에서 어떤 고정 6개 조합도 동일한 확률이므로, 검증되지 않은 과거 패턴 대신 3세트 전체의 번호 커버리지를 최대화한다.

## 평가

`src/core/weekly-cycle.js`는 목표 회차가 발표되면 다음을 기록한다.

- 세트별 적중 번호와 적중 수
- 보너스 번호 포함 여부
- 세트별 등수
- 3세트 최고 및 평균 적중 수
- 3개 이상 적중한 세트 수
- 최근 52주의 누적 평가 주차, 평균 적중 수, 당첨 세트 및 당첨 주차

`적중 수 / 6`을 정확도라고 부르거나 여러 세트 중 최고값을 모델 정확도로 사용하지 않는다. 지난 결과는 분석과 기록에만 쓰며 다음 번호의 가중치로 학습하지 않는다.

## 기록 무결성

각 주간 기록에는 기준/목표 회차와 날짜, 생성 시각, 판매 마감 시각, 엔진 버전, 결정적 seed, 데이터 버전, 추천 3세트가 들어간다. 평가 전 다음을 검증한다.

- `targetDraw === baseDraw + 1`
- 생성 시각이 목표 회차 판매 마감 전
- 엔진 버전과 seed가 기준 회차와 일치
- 추천 번호가 결정적 엔진 재실행 결과와 일치
- 정확히 3세트이며 전체 18개 번호가 서로 다름

서비스 워커는 당첨 데이터와 주간 추천 파일에 network-first 정책을 적용해 오래된 캐시로 사후 추천이 생성되는 것을 막는다.
